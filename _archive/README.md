# _archive —— 工程收藏品

这个目录存放"收藏品"：做完的项目里沉淀下来的开发 skill、工作流文档等工程纪念品。

- 下划线开头的目录不参与 Jekyll 站点构建，只进 git 仓库，不影响线上页面。
- 收藏品按 `skills/<skill 名>/` 组织，每个 skill 自带 README 说明来源与收藏原因。
- 部分收藏品在官网「藏品库」页面向公开展出：[/collection/](https://lyzbcy.github.io/corporate-website/collection/)（展品数据见 `_data/collection.yml`）。
- 收录公司项目相关内容前必须脱敏：内网地址、仓库标识、同事姓名、内部链接一律泛化，原始未脱敏版本留在公司内网工作区。
