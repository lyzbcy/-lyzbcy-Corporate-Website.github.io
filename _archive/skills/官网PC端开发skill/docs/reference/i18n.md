# Reference：中英文国际化（i18n）

## 机制

- 运行时替换：`i18n/i18n.js` 根据 URL 参数（如 `?lang=en`）选择语言包，扫描 `data-i18n` / `data-i18n-src` / `data-i18n-alt` / `data-i18n-title` 等属性替换内容
- 语言包：
  - 站点级公共文案：`i18n/common.zh.js` / `i18n/common.en.js`（header、footer、首页 banner 等）
  - 页面级文案：`i18n/pages/<页面名>.zh.js` / `.en.js`
- HTML 中写中文默认值 + i18n 属性，key 命名 `页面.模块.位置`（如 `about.contact.office4.address`）

## 改文案检查清单

1. 找到 key 所在的 zh 和 en 两个文件，**两边都要改**，只改一边会导致中英不一致
2. 新增 key 时 zh/en 同步新增；英文缺失会直接显示 key 或空白
3. 纯改 HTML 默认值而漏改语言包 = 白改（运行时会被语言包覆盖）
4. 图片按语言区分时用 `data-i18n-src`，中英两份图都要放
5. 结构化数据（如 about.html 里的 JSON-LD）是写死的，需单独处理

## 语言切换验证

本地 `npm run preview:local` 后，分别访问默认（中文）和 `?lang=en` 确认两种语言都正确。
