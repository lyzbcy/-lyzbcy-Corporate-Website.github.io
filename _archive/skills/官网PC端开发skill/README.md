# 官网 PC 端开发 Skill（收藏品）

## 这是什么

2026 年 9 月「官网 Banner 企微 AI 宣传更新」项目（一天走完开发→CR→提测→上线）沉淀下来的开发 skill，归档收藏于 2026-09-03。

这个项目的官网是一个纯静态多页站（HTML + CSS + jQuery + 运行时 i18n，无构建编译），改起来不难，难的是不漏：中英文两份语言包、JSON-LD、地图坐标、静态资源 `?v=` 缓存版本号，每一处漏掉都会变成线上事故。这套 skill 把这些坑固化成了「渐进式披露文档 + 变更文件数据库 + DoD 清单」，让下一次官网需求可以照单执行。

## 为什么收藏

- 它代表一种小体量项目的工程化思路：需求再小，也用文档数据库管变更、用 DoD 管质量，而不是靠记性。
- 结构上是一份典型的 agent skill 设计样本：SKILL.md 入口 + docs/ 按需渐进式披露 + reference 数据库，AI 接手项目时先读它就能少走弯路。

## 目录

- `SKILL.md` —— skill 入口（必读项、改动类型路由表、DoD、开发铁律）
- `docs/agent.md` —— docs 导航；`docs/project.md` —— 项目介绍与版本记录；`docs/todo.md` —— 进度
- `docs/requirements/` —— 按日期归档的需求文档
- `docs/reference/` —— homepage-banner（banner 改动套路与设计规格）、i18n（中英文适配清单）、change-log（变更文件数据库）

## 脱敏说明

公开收藏版已去除：内网 GitLab 地址、仓库实名、公司名、同事姓名、内部设计稿链接、公众号链接、办公地址与坐标。文档中的文件路径保留原结构（`page/about.html` 等为泛化后的示意路径）。未脱敏原始版存于公司内网工作区。
