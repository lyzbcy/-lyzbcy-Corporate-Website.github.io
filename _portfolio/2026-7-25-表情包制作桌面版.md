## 📊 项目信息
- **完成时间**: 2026 年 7 月（已上线）
- **项目类型**: macOS 桌面应用（支持 macOS 11+）
- **核心技术**: 桌面壳 + 本地 Agent 服务（loopback + token）、AI 故事生图、洋红底自动抠图、微信规格切图
- **在线体验**: [sticker-maker 首页](https://lyzbcy.github.io/sticker-maker/)

## 💡 这个 app 解决什么问题

做一套微信表情包，本来要会拼图、会抠图、懂微信的尺寸规范、还会用上架后台——每一件都不难，但全串起来门槛很高。而且工具是散的：画图一个软件、抠图一个软件、改尺寸又一个软件。

这个 app 把整件事收进一个普通人也能用的软件里：从 base 图、AI 故事生图、自动切图抠图，到微信上架素材和提交入口，一条龙走完。

## 它和 Skill 版有什么不同

之前我做过一个表情包制作 Skill（`wechat-sticker-maker`），面向的是开发者和 AI 助手——本质是一组命令行脚本，要会用终端、懂参数，生图还要自己接环境。

这个桌面版做的不是"功能升级"，而是**受众迁移**：把同一套能力重新包装，让不懂技术的普通创作者也能用。

| 维度 | Skill 版 | 桌面版 |
|---|---|---|
| 谁用 | 开发者 / AI 助手 | 普通人 / 画师 / 自媒体 |
| 怎么用 | 敲命令、传参数 | 双击打开，点按钮 |
| 生图 | 自己接环境 | 软件内引导配置 |
| 上架 | 只出素材 | 一键准备素材 + 提交入口 |
| 自动化 | 本就是脚本 | 内置本地 Agent，进阶用户仍可脚本接管 |

关键是：**桌面版没有把 Skill 版丢掉**。普通用户走可视化界面，进阶用户仍能通过内置的本地 Agent 接口（`/run`、`/publish`）让 AI 接管重复劳动——同一个 app，两种使用层级。

## 2. 核心功能

### 🎨 一条龙，不只是"生一张图"
很多工具只会生成单张图。但表情包是一套——有角色连贯性、有情绪主题、还要凑齐微信要求的张数和规格。这个 app 处理的是"一弹"这个完整单位。

### 📖 故事生图
每 4 张图组合成一个带起承转合的小故事，保持顺序和含义词不被打乱——不是随机拼贴，而是成组地讲一个情绪。

### ✂️ 自动切图 + 抠图
生成时固定用洋红色背景，完成后自动抠图，输出符合微信规范的 240×240 主图和 50×50 聊天页图标。

### 📦 微信上架一条龙
一键准备横幅、封面、图标等提审素材，自动生成含义词表和信息模板，软件里直接发起上架流程。不用再单独翻微信开放平台的文档对尺寸。

## 3. 四步得到一弹成品

<ol class="project-flow">
  <li><strong>准备角色</strong><br>配置依赖环境，上传底图并设定抽取概率。</li>
  <li><strong>选择模式</strong><br>图库、故事或排列组合生图，选网格资源（1×1、2×2 等）。</li>
  <li><strong>自动制作</strong><br>软件自动执行生图、抠图与素材打包。</li>
  <li><strong>检查并提交</strong><br>系统文件夹查看成品，软件内直接发起上架。</li>
</ol>

## 4. 🤕 技术难点

### 把 Skill 装进普通人的电脑
Skill 版依赖命令行、Python 虚拟环境和外部生图服务，这些对开发者是日常，对普通用户每一步都是劝退点。桌面版要做的是把这些"开发者习以为常的前提"全部藏到软件背后：双击即用、安装脚本自动处理 macOS 隔离提示、生图环境引导式配置。

### 一条龙的连贯性
单张图生成容易，一整套表情包难——角色要在 16 或 24 张图里保持一致，情绪要有主题，张数要够微信审核，每张尺寸还要合规。中间任何一环断了，用户拿到的就是一堆没法用的图。难点不在某个算法，而在把生图、抠图、切图、命名、规格校验、上架素材这些散落的步骤缝成一条不掉链子的流水线。

### 同时照顾两种用户
如果只做可视化界面，会丢掉原本 Skill 版的自动化能力，进阶用户失去批处理价值；如果只做脚本接口，普通人用不了。最终用"可视化 + 本地 Agent 服务"两层并存解决——普通用户点按钮，进阶用户用 loopback + token 保护的本地 API 让 AI Agent 接手重复工作，一个 app 两种用法互不打架。

## 5. 项目复盘

这次最值得留的不是某个功能，而是"把同一套能力换一种交付方式"这个思路：**Skill 解决的是"能不能做"，桌面 app 解决的是"普通人能不能用"**。很多 AI 工具卡在"技术上很酷但只有开发者会用"这一步，把它重新包装成普通软件，受众能从一个圈子扩展到完全不同的人群。

而保留脚本接口这件事也很关键——平民化和可编程不是对立的，一个软件可以同时让两种人各自舒服。
